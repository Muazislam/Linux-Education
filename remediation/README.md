# Remediation

Use this directory for targeted exercises created from repeated mistakes, weak assessments, or high hint dependency.

Each remediation task should name the competency gap, evidence that revealed it, task objective, constraints, and reassessment criteria.

Template:

- `remediation/REMEDIATION_TEMPLATE.md`

Use:

- `remediation/active/` for assigned remediation.
- `remediation/completed/` for finished remediation with reassessment evidence.

Do not create vague remediation such as "review networking." Tie remediation to a specific evidence-backed weakness.
