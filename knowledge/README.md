# Knowledge Base

This directory stores learner-authored understanding, not copied documentation.

Use:

- `knowledge/concepts/` for major concepts.
- `knowledge/commands/` for command notes tied to use cases and risks.
- `knowledge/architecture/` for system architecture notes.
- `knowledge/documentation-notes/` for documentation research records.
- `knowledge/mental-models/` for evolving mental models.

Templates:

- `knowledge/CONCEPT_TEMPLATE.md`
- `knowledge/MENTAL_MODEL_TEMPLATE.md`
- `knowledge/DOCUMENTATION_RESEARCH_TEMPLATE.md`

Knowledge notes should link to evidence, mistakes, labs, or assessments when they explain a real learning change.
