# Assessments

Assessment records must include:

- objective;
- competencies tested;
- environment;
- evidence reviewed;
- outcome;
- reasoning evaluation;
- safety evaluation;
- documentation use;
- verification quality;
- hint level required;
- mastery-level implication;
- remediation if needed.

Do not mark mastery without evidence.

- `assessments/final/` - final Arch practical exam records.
