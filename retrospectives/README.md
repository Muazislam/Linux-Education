# Retrospectives

Use this directory for weekly or periodic reflections.

Keep retrospectives useful and short unless a major lab or incident requires more detail.

Templates:

- `retrospectives/WEEKLY_REVIEW_TEMPLATE.md`
- `retrospectives/PERIODIC_REVIEW_TEMPLATE.md`

Use:

- `retrospectives/weekly/` for weekly reviews.
- `retrospectives/monthly/` for monthly or phase reviews.
- `retrospectives/long-term/` for major curriculum retrospectives.

Retrospectives should identify strongest competencies, weakest competencies, recurring mistakes, mental-model changes, remediation, and next objectives.
