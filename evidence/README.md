# Evidence

Store or reference learner-provided evidence here when useful:

- command output;
- logs;
- configuration snippets;
- scripts;
- screenshots;
- written reasoning;
- before/after state;
- verification output.

Never store secrets. Redact passwords, tokens, API keys, private keys, and sensitive personal data.

Phase 0 evidence template:

- `evidence/phase-0/sample-evidence.md`

Lab evidence template:

- `evidence/LAB_EVIDENCE_TEMPLATE.md`

Evidence should be enough to evaluate reasoning and verification, but not so much that logging becomes the main activity.
