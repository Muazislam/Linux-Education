# Milestones

Last updated: 2026-08-26

Milestones are based on demonstrated capability, not lesson completion.

| Milestone | Evidence Required | Status | Evidence |
|---|---|---|---|
| Phase 0 complete | Lab decision, safety checklist, evidence sample, baseline diagnostic | Not complete | None |
| First safe host inspection | Read-only command evidence and interpretation | Not complete | None |
| First completed lab evidence | Lab evidence record accepted | Not complete | None |
| First mistake archived | Mistake record with remediation decision | Not complete | None |
| First troubleshooting incident | Incident record with root cause and verification | Not complete | None |
| First competency at L3 | Guided practical evidence | Not complete | None |
| First competency at L5 | Troubleshooting evidence | Not complete | None |
| First recovery competency at L6 | Recovery evidence in disposable environment | Not complete | None |
| First weekly retrospective | Weekly review completed | Not complete | None |
| First cold-start assessment | Assessment record completed | Not complete | None |
