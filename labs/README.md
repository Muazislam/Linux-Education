# Labs

Labs must follow `INSTRUCTOR_PROTOCOL.md`.

Each lab should define objective, environment, initial conditions, constraints, allowed inspection, prohibited actions, required evidence, expected final state, and assessment criteria.

Learner lab reports should use the standard lab state report from `INSTRUCTOR_PROTOCOL.md`.
