# Learning Log

Use this directory for session learning records. Do not fabricate observations.

Small sessions may need only a short entry. Major labs, assessments, or incidents require evidence references.

Use `learning-log/TEMPLATE.md` for significant learning sessions.

Recommended structure:

- `learning-log/daily/` - normal session notes.
- `learning-log/weekly/` - weekly learning summaries when useful.
- `learning-log/learning-log.md` - index of learning records.

Important concept sessions must record "My Initial Understanding" so changes in mental model are visible.
