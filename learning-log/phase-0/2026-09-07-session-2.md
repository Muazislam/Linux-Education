## What I Studied

- Difference between the root directory (`/`) and user home directory (`~` / `/home/username`).
- Efficient manual page searching using forward slash (`/pattern`) in `less`/`man`.

## What I Discovered & Clarified
- File extensions (`.html`, `.js`, `.txt`) are naming conventions for user/app convenience in Linux, not kernel-enforced file types.
- A file is identified as a directory or regular file by its filesystem metadata (`d` vs `-` in `ls -l` or via the `file` command).
- Permissions (`-rw-------`) are independent of whether a file is hidden; any file can have any valid permission bits.
- Inside `man`, typing `/all` or `/-a` immediately jumps to the exact flag definition without reading the whole page manually.
