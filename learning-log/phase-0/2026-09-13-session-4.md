2. **Unix/Linux I/O Architecture & Mental Model**:
   - **Everything is a File**: Recognized that devices (keyboard, monitor/console) are treated as file abstractions by the operating system.
   - **Three Standard Streams**:
     - `stdin` (File Descriptor `0`): Input stream, attached by default to the terminal keyboard.
     - `stdout` (File Descriptor `1`): Normal output stream, attached by default to the terminal display.
     - `stderr` (File Descriptor `2`): Diagnostic/error stream, decoupled from stdout so error messages can be captured or separated from data payloads.
   - **Process Hierarchy**: Understood that the parent process (the shell) creates and wires these streams for child processes upon execution.
   - **Low-Level vs Buffered I/O**: Clarified the distinction between raw kernel integer file descriptors (`0`, `1`, `2`) and higher-level C library `FILE *` pointer structures (`stdio.h` macros).
   - **POSIX Standards**: Explored what POSIX.1 compliance means for cross-platform Unix/Linux behavior.

## What I Discovered & Clarified
- Manual pages are indexed by exact topic or keyword, not natural language sentences. When the exact page name is unknown, `man -k <keyword>` is the professional method to discover relevant entries.
- Technical documentation is dense and exhausting on the first few passes, but navigating through sections (`SYNOPSIS`, `DESCRIPTION`) and understanding C declarations reveals the exact system contract without guessing.
- File descriptors are process-specific integer tables maintained by the kernel, decoupling programs from the physical hardware.
