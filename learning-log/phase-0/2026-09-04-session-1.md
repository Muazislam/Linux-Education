## What I Initially Got Wrong
- Syntax error on `cat /etc/* -release` due to extra whitespace making `-release` parse as command flags.
- Assumed `uname -v` would output the distribution release version rather than `uname -r`.

## What I Discovered
- Spaces in shell commands separate arguments; whitespace between wildcard `*` and suffix breaks globbing.
- `uname -r` prints the kernel release string (e.g. `7.1.11-arch1-1`), while `uname -v` prints the compilation timestamp and SMP build string.
- Local manual pages provide precise flag definitions that disambiguate release vs version.

## Instructor Feedback & Pragmatic Programmer Evaluation

- **Don't Program by Coincidence / Don't Administer by Coincidence:** Moving from running random Google/AI snippets to understanding *why* commands work (e.g., `$0`, globbing flags).
- **Use the Source & Native Tools:** Shifting from Google AI summaries to local man pages (`man uname`, `cat --help`).
