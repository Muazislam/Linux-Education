# Troubleshooting Records

Use this directory for break-fix exercises, incident investigations, and root-cause analyses.

Follow:

```text
OBSERVE -> DEFINE -> COLLECT EVIDENCE -> HYPOTHESIZE -> TEST -> ELIMINATE -> ROOT CAUSE -> REPAIR -> VERIFY -> DOCUMENT
```

Templates and indexes:

- `troubleshooting/INCIDENT_TEMPLATE.md`
- `troubleshooting/troubleshooting-patterns.md`

Use:

- `troubleshooting/incidents/` for significant failures.
- `troubleshooting/root-cause-analysis/` for deeper RCA records.

If the learner changes configuration before collecting evidence, record that as a diagnostic or verification weakness.
