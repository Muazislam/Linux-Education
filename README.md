# Linux / Arch Engineering Learning Repository

This repository stores a persistent Linux, Unix, systems administration, troubleshooting, and Arch Linux learning system.

Any AI instructor must begin with `INSTRUCTOR_PROTOCOL.md`, then follow `instructor/BOOTSTRAP.md`. The protocol is the authoritative behavioral contract; other files provide state, curriculum, evidence, and progress.

The human-facing implementation plan is `IMPLEMENTATION_PLAN.md`.

The learning-system implementation report is `IMPLEMENTATION_REPORT.md`.

## Current Status

The curriculum architecture has been initialized. No practical Linux competency has yet been demonstrated in this repository.

Next step: work through `curriculum/phases/phase-0.md`, beginning with curriculum review, lab environment selection, safety confirmation, evidence format, and the baseline diagnostic.

## Core Directories

- `instructor/` - onboarding, current state, session protocol, handoff rules.
- `curriculum/` - roadmap and competency architecture.
- `curriculum/phases/` - phase-specific implementation plans.
- `modules/` - module plans and materials as modules begin.
- `progress/` - progress, competency levels, weaknesses.
- `learning-log/` - session learning records.
- `evidence/` - submitted evidence of work.
- `labs/` - lab definitions and reports.
- `assessments/` - assessment records.
- `mistakes/` - classified errors and recurring patterns.
- `troubleshooting/` - incident records and break-fix exercises.
- `remediation/` - targeted remediation work.
- `retrospectives/` - weekly or periodic reflections.
- `knowledge/` - concepts, commands, documentation notes, and mental models.
- `decisions/` - durable engineering and curriculum decisions.
