# Handoff Protocol

Use this protocol when changing instructors or when creating a continuity summary after substantial work.

## Outgoing Handoff Summary

Create or update a handoff record containing:

```text
DATE:
CURRENT PHASE:
CURRENT MODULE:
CURRENT TASK:
RECENT ACHIEVEMENTS:
CURRENT WEAKNESSES:
UNRESOLVED QUESTIONS:
RECENT MISTAKES:
MASTERY CHANGES:
PENDING REMEDIATION:
NEXT RECOMMENDED TASK:
IMPORTANT INSTRUCTOR OBSERVATIONS:
FILES UPDATED:
EVIDENCE REFERENCES:
```

Store handoff records in `instructor/handoffs/` when the directory exists or create it when needed.

## Incoming Instructor Duties

The incoming instructor must verify the handoff against repository evidence. Do not blindly trust a handoff if it conflicts with progress files, assessment records, lab evidence, or mistake logs.

If contradictions exist, prefer:

1. recent direct evidence;
2. repeated demonstrations;
3. formal assessment records;
4. progress markers;
5. learner self-reporting.

Record significant corrections in the relevant progress or assessment file.
