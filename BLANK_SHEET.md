### Task D5: The Process Lifecycle & Inspection

Imagine you are troubleshooting a machine. In your own words and with harmless inspection  
 commands, explain how you would distinguish between these 4 states of a program (for example,
a web browser like firefox or a server like nginx):

1. State A: The program is NOT installed on the system.
   What command would you run to prove it isn't installed, and what output or exit code would you
   expect?
2. State B: The program IS installed, but it is NOT currently running.
   How do you prove it exists on disk, but has no active process running in memory?
3. State C: The program IS running normally.
   What tool or command would you use to find its Process ID (PID) and prove it is active?
4. State D: The program IS running, but it is consuming too many system resources (CPU or RAM).
   What command would you run to observe resource consumption and identify the offending process?
   ──────
   Take your time to test these concepts in your terminal and reply with your reasoning and  
   commands!
