# Error Log

Record important failures using this structure:

```text
DATE:
TASK:
EXPECTED RESULT:
ACTUAL RESULT:
INITIAL HYPOTHESIS:
EVIDENCE:
ROOT CAUSE:
ERROR CATEGORY:
CORRECTION:
LESSON:
RECURRING PATTERN:
REMEDIATION:
```

No learner errors have been recorded yet.

For structured mistake records, use:

- `mistakes/MISTAKE_TEMPLATE.md`
- `mistakes/mistake-index.md`

Store detailed records under the relevant category directory.
